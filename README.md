# AI起名生成器

基于 **Node.js + Vercel Serverless + OpenAI(流式) + Supabase** 的 AI 起名网页应用。

## 功能
- ✅ 用户输入起名需求，SSE 流式输出 3 组名字 + 寓意解释
- ✅ 每次生成自动保存：用户需求、名字方案、使用模型 → Supabase
- ✅ 密钥全部从环境变量读取，无硬编码

## 项目结构
```
├── api/generate-name.js   # Vercel Serverless 流式接口（Edge Runtime）
├── index.html             # 前端页面
├── vercel.json            # Vercel 配置
└── package.json
```

## Supabase 建表 SQL
在 Supabase → SQL Editor 执行：
```sql
create table if not exists ai_name_records (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now(),
  user_prompt text not null,
  result_json jsonb not null,
  model_name text not null
);

-- 生产环境建议开启行级安全
alter table ai_name_records enable row level security;
```

## Vercel 环境变量
| Key | Value |
|---|---|
| `OPENAI_API_KEY` | OpenAI API Key |
| `SUPABASE_URL` | Supabase 项目 URL |
| `SUPABASE_ANON_KEY` | Supabase anon public key |
| `MODEL_NAME` | 模型名（可选，默认 `gpt-4o-mini`） |

## 部署
1. 导入本仓库到 Vercel
2. 配置上方环境变量
3. Deploy 即可访问
